# RESQ360 - Emergency Response System

RESQ360 is a life-saving emergency response platform designed to bridge the gap between accidents and medical assistance. Using advanced sensor-based detection and real-time coordination, RESQ ensures that help arrives when every second counts.

## 🚀 Key Features

- **Instant Crash Detection**: Leverages smartphone sensors to detect impact force and vehicle orientation in real-time.
- **Auto-Alert System**: Automatically notifies emergency services, hospitals, and family members within 30 seconds of an incident.
- **High-Precision GPS**: Provides accurate location tracking even in low-connectivity areas using multi-satellite triangulation.
- **Smart Coordination**: Bridges the gap between rescue teams, insurance providers, and medical staff for seamless triage.

## 🛠️ Tech Stack

- **Frontend**: React (with Vite)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React & React Icons
- **Language**: TypeScript

## 💻 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (Latest LTS recommended)

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

### Development

Run the local development server:
```bash
npm run dev
```

The application will be available at `http://localhost:5173`.
